# vaultrow

Vault structured JSON row payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/vaultrow/

## Install / run

```bash
git clone https://github.com/theworker02/vaultrow.git
cd vaultrow
node src/cli.js
node --test
```
