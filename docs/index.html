Overview

Vault structured JSON row payloads without a heavyweight toolkit. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/vaultrow.git
cd vaultrow
node src/cli.js --help
node --test
